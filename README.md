# Deeggarsa Creator (TikTok fakkaatu, Itiyoophiyaa)
Tarkaanfii deploy:
1. Folder kana GitHub repo’tti ol-fe’i.
2. Render: New Web Service. Build: `npm install`. Start: `npm start`.
3. Environment: DATABASE_URL (Neon), JWT_SECRET, CLOUDINARY_URL, ADMIN_PHONE (lakkoofsa kee, +2519...).
4. Lakkoofsa ADMIN_PHONE’n galmaa’i, admin ta’uuf.
Gift, coins fi baasii: config.js keessatti jijjiirta.
